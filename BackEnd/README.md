# BackEnd (deferred)

The backend API and database implementation are deferred from phase 1. The current application uses hardcoded, in-memory data entirely within `FrontEnd/` and makes no backend calls.

A future approved backend implementation should replace the frontend data seam in:

- `FrontEnd/src/data/MaintenanceDataContext.js`
- `FrontEnd/src/data/commands.js`

The earlier API and schema proposal remains available in the [superseded full-stack plan](../../kavia-docs/CodeWiki/Plans/predictive-maintenance-alert-work-order-system.md).

No backend code belongs in this directory until a backend plan is approved.
